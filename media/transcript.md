# ArborKnowledge Studio — bilingual film transcripts

Real local app footage with fictional data. Visible application labels were translated into English only for the presentation; this is not shipped product localization.

Azure Speech voices: German **de-DE-ConradNeural**, English **en-GB-RyanNeural**.

The four versions use language-specific scene and caption timing.
