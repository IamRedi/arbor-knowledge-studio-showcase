# Media provenance and rights

This public repository contains original presentation text, two self-authored SVG illustrations and screenshots of ArborKnowledge Studio. The screenshots were captured from the real local application with an isolated SQLite database populated only by self-authored **fictional** case records. Names such as “Nordpark 07” identify a demo scenario, not a real inspection, person or customer.

The two MP4 films are edited from actual local Chrome recordings of that same fictional application case and self-authored title cards. For the public captures only, visible application UI text was translated to English in the browser before recording. This is an editorial presentation layer, not a claim that the product ships with English localization; application routes, behavior, data and private source code were unchanged. German narration was synthesized locally with a Windows system TTS voice. Captions and transcripts were written for this demo. No music, stock media, cloned voice or third-party footage is used. The films show no successful live AI provider call.

No private source code, Git history, API credential, owner database, licensed literature, third-party PDF or personal data is included. No application screenshot was synthesized or generated as a substitute for a running feature.
